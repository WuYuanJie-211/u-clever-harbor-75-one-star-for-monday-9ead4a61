A single line of plain text: a one-star review of Monday, written as though Monday were a restaurant.

The entry is generated by `main.ts` (Node, `fs` only): it checks the line against the competition gate — at most 25 words — then writes it directly to `/output/entry.txt` with mode `0644`.

Run `node main.ts` to write the line to `/output/entry.txt`.
